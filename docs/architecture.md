# Архітектура

Проєкт розділено на незалежні шари.

1. `grammar/sipl.lark` задає лексику та синтаксис SIPL.
2. `parser.py` будує конкретне дерево Lark і перетворює його на власне AST.
3. `ast.py` містить типізовані вузли та позиції `SourceSpan`.
4. `interpreter` виконує AST, змінює стан і створює події trace.
5. `semantics` рекурсивно будує семантичний терм з AST.
6. `visualization` експортує конкретне дерево у text, JSON, DOT та SVG.
7. `cli.py` надає єдиний інтерфейс для всіх можливостей.

Парсер, інтерпретатор і семантика не залежать від CLI. Їх можна імпортувати як бібліотеку. Візуалізація використовує реальне дерево парсингу та не містить заготовлених зображень.

## Потік даних

```text
SIPL source
    -> Lark parse tree
    -> typed AST with SourceSpan
    -> interpreter and trace
    -> semantic term
```

Дерево Lark використовується для VIS-01. Власне AST використовується для виконання та побудови семантичного терму.
